# HipMRI Prostate Segmentation

COMP3710 Pattern Recognition

Project 2: HipMRI Prostate Segmentation

## Overview

This project investigates prostate segmentation using
2D U-Net and 2D Improved U-Net models on the HipMRI dataset.

The standard 2D U-Net will be implemented first as a baseline,
followed by the Improved U-Net for comparison.
